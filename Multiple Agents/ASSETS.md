# Card art attribution

The card face sheet [`static/original-hungarian-tell-set.jpg`](./static/original-hungarian-tell-set.jpg) comes from **SZERVÁC Attila**'s photograph “Original Hungarian Tell set”. Source page: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Original-Hungarian-Tell-set.jpg).

License: [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/).

The Commons original is 4,640 × 3,488 pixels. The local file is its 1,280 × 962 Wikimedia thumbnail, used as a CSS background sprite. The app crops the first five rank columns from each of the four suit rows; this crop is applied in CSS rather than saved as separate card files. The resized local image and its sprite use are provided under the same CC BY-SA 4.0 license. Changes from the original are resizing and on-screen cropping; this project is not endorsed by the photographer.
